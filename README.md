# 번역 전에 한 번 더

이 앱은 AI에게 번역을 맡기기 전에, 붙여 넣은 글 속 이름·연락처·소속 같은 개인정보를 먼저 찾아 가려 주어 번역 요청에서 개인정보가 새는 일을 줄이도록 돕습니다.

ALEPH 과정 과제 「마지막 B · 내 논문을 반영한 애플리케이션」으로 만든 앱입니다. 바탕이 된 논문은 「AI 챗봇 대화에서 요청 유형에 따른 개인정보(PII) 노출 확률 비교 — 번역 요청과 코드 수정 요청을 중심으로」입니다.

## 무엇을 하나요

논문에서는 공개된 Trust No Bot 주석 데이터(WildChat-1M 기반)를 다시 분석해, 번역 요청 212건 중 116건(54.72%)에 개인정보성 내용이 들어 있었고 코드 수정 요청은 301건 중 13건(4.32%)에 그쳤다는 결과를 얻었습니다. 번역을 맡길 때는 남의 메일이나 메시지를 통째로 붙여 넣는 일이 많기 때문입니다.

이 앱은 그 결과를 도구로 옮긴 것입니다. 번역을 맡기기 전에 글 속 개인정보를 찾아 표시하고, 가린 글을 복사해 AI에게 보낸 뒤, 돌아온 번역문에 원래 값을 다시 넣어 줍니다.

## 누구에게 도움이 되나요

- 해외 거래처 메일이나 업무 메시지를 AI 번역에 맡기는 직장인
- 교수님께 보낼 메일, 과제, 지원서를 번역하는 학생
- 팀원에게 "AI에 붙여 넣기 전에 한 번 확인하자"는 습관을 만들어 주고 싶은 사람

## 할 수 있는 세 가지

1. **글 붙여 넣고 「점검하기」** — 이메일, 전화번호(010·02·+82), 주민번호 모양의 번호, 카드번호 모양의 16자리 숫자, 링크, 영문 이름, 한국어 이름(직함이나 "보내는 사람:" 같은 표시로 판단), 회사·학교·병원 이름, 주소를 찾아 글에 색으로 표시합니다. 논문의 범주(학업·교육, 인용된 이메일·메시지, 재정·기업, 건강, 구직 등)에 해당하는 말도 함께 보여 줍니다. 잘못 잡힌 항목은 체크를 풀면 가리지 않습니다.
2. **요청 유형 고르기(번역 / 코드 수정 / 기타)** — 논문에서 같은 유형의 요청에 개인정보가 얼마나 자주 들어 있었는지 신뢰구간과 함께 보여 주고, 범주별 비율을 막대그래프로 그려 내 글에 있는 범주를 따로 표시합니다.
3. **「가려서 복사하기」와 「되돌리기」** — 찾은 값을 `[이름1]`, `[이메일1]`, `[전화1]`, `[주소1]`, `[소속1]` 같은 표시로 바꿔 복사합니다. 화면에 대응표가 남으니, AI가 돌려준 번역문을 붙여 넣고 「되돌리기」를 누르면 표시 자리에 원래 값이 다시 들어갑니다.

「예시 글 넣기」 버튼으로 지어낸 업무 메일과 코드 수정 요청을 바로 넣어 볼 수 있습니다.

## 실행 방법

설치할 것도, 환경 변수도 없습니다.

- `index.html` 을 브라우저로 바로 열거나
- 이 폴더에서 `npx serve .` 를 실행한 뒤 안내된 주소로 들어가세요.

`file://` 로 열었을 때 브라우저가 ES 모듈을 막는다면 두 번째 방법을 쓰세요. 클립보드 복사가 막힌 환경에서는 가린 글이 선택된 상태로 남으니 Ctrl+C(맥은 ⌘+C)로 복사하면 됩니다.

## 시험 실행

```
node --test
```

탐지, 가리기·되돌리기 왕복, 빈 입력과 이상한 입력, 10만 자 입력의 처리 시간(1초 안), 앱 파일에 실제처럼 보이는 비밀값이 없는지를 확인합니다.

## 데이터와 개인정보

- 앱에 들어 있는 데이터는 논문의 집계 수치와 지어낸 예시 데이터뿐입니다. 예시의 이름(홍길동, 성춘향, Jane Doe), 이메일(hong@example.com), 전화번호(010-1234-5678), 주소는 모두 실제와 관계없습니다.
- 모든 처리는 브라우저 안에서만 이루어집니다. 서버가 없고, 입력한 글과 대응표를 저장하거나 어디로 보내지 않습니다. 창을 닫으면 모두 사라집니다.

## 한계

- 원 논문의 48%와 16%는 Azure PII 탐지를 쓴 다른 분석에서 나온 수치라서 이 앱의 수치와 바로 비교할 수 없습니다.
- 논문 분석에서 실명을 찾을 때 쓴 정규식은 한국어 이름을 잘 잡지 못합니다. 실제 실명 비율은 더 높을 수 있습니다.
- 이 앱의 탐지는 정해진 규칙(정규식과 단어 목록)만 씁니다. 직함 없이 이름만 쓴 경우, 외국 주소, 사정이 담긴 문장(건강·연애 이야기 등)처럼 규칙으로 잡기 어려운 개인정보는 놓칠 수 있고, 개인정보가 아닌 말을 잘못 잡을 때도 있습니다. 보내기 전에 꼭 한 번 더 읽어 보세요.
